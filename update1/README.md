# LaTale 2026 2Q Update 1 (Light of the Soul) - English build

English version of https://www.latale.com/event/2026/2q-update1/, rebuilt as plain HTML5 + CSS3 + Vue 2 (no build step).
The Korean clone lives next to it in `LT/2026_2q_update1_vue2`.

## Running it

Open `index.html` in a browser (double-click / `file://` works). No build, no `npm install`, no server.

## What is different from the Korean page

- All copy is English. Place, monster and NPC names use the English spelling printed in the original artwork
  where there is one (Linford, Aether Road, Elone, Nuckalava, Hailee, Kyril ...); the rest is romanized here and is not official.
- Korean lettering baked into images is replaced by live text (`css/en-text.css`, loaded last):
  titles and names are plain text, and inside cards / panels the Korean text area is cut out of the image and repainted
  in the same colour with the English text on top.
- Game UI screenshots are still the Korean client.
- Removed, as in the 1Q English build: login, GAME START, the left banner panel, the copyright footer.
  The home icon goes to https://latale.papayaplay.com/ (`js/config.js`).
